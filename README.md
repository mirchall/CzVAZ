# Counter-VAZ

Babylon.js tabanlı FPS oyunu. Windows kurulumu ve tek dosyalık HTML sürümü birlikte yayınlanır.

## İndir

[Son sürüm ve Windows kurulumu](https://github.com/mirchall/CzVAZ/releases/latest)

Her sürümde Windows kurulum EXE'si, tam HTML oyun dosyası ve otomatik güncelleme dosyaları bulunur. Büyük oyun dosyaları Releases bölümündedir. `.counter-vaz/releases/` klasörü sürüm dosyalarının boyutlarını ve SHA-256 özetlerini tutar.

## Otomatik güncelleme

GitHub güncellemesi etkin ilk Windows sürümü **1.4.0**'dır. Önceki sürümlerden geçerken bu kurulumu bir kez yükleyin. Sonraki yayınlar oyun açılışında kontrol edilir, indirilir ve kayıtlar kaydedilerek kurulur. Kurulumdan sonra oyun yeniden açılır. İnternet yoksa mevcut sürüm açılabilir. Güncelleme ekranını atlayıp oynamaya devam ederseniz maç ortasında zorunlu yeniden başlatma yapılmaz.

Oyun kayıtları sürüm dosyalarından ayrı kullanıcı klasöründe şifreli tutulur. GitHub hesabı veya şifresi oyuncuların uygulamasına eklenmez.

Sunucu adresi: `https://czvazsv1.loca.lt`.

Windows kurulumları şu an Authenticode sertifikasıyla imzalanmamıştır.
