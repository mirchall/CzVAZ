# Counter-VAZ — Windows güncellemeleri

Bu depo yalnızca Windows kurulum ve otomatik güncelleme dağıtımı içindir. Oyun kaynak kodu, HTML dosyası, uygulama kaynakları, sunucu kodları ve kaynak arşivleri burada yayımlanmaz. Kaynaklar geliştiricide özel olarak saklanır. Git geçmişinde yalnızca açıklama ve sürüm dosyası özetleri bulunur.

## İndir

[Windows için son sürüm](https://github.com/mirchall/CzVAZ/releases/latest)

## Güncelleme

Oyun her açılışta yeni sürümü denetler. Yeni sürüm varsa indirme yüzdesi ve “Güncelleme kuruluyor, bekleyin” ekranı görünür; kayıtlar kaydedilir, kurulum yapılır ve oyun yeniden açılır. Güncel sürüm yeniden kurulmaz. 1.4.1 itibarıyla güncelleme kontrolü zorunludur; bağlantı hatasında Tekrar Dene / Çıkış sunulur.

GitHub güncelleyicisi etkin 1.4.0 sürümü yeni sürümü açılışta alabilir. 1.3.1 ve daha eski kurulumlar için son Windows kurulumunu bir kez yükleyin.

EXE paketlemek teknik incelemeyi tamamen engellemez. Sunucu kaynakları dağıtılmaz ve istemciye GitHub erişim anahtarı gömülmez. Kurulumlar şu an Authenticode sertifikasıyla imzalanmamıştır.
